# にこまる (BridalHub)

**案件管理・招待・宿題(提出物)管理・準備シート・AI補助**を提供する。卒業制作プロジェクト。

## 設計上の技術構成 (設計書 v1.1 より)

| 層 | 採用 | 備考 |
| --- | --- | --- |
| フロント/ホスティング | Next.js + Vercel (Hobby枠) | 制約起点で構成決定 |
| DB / 認可 | Supabase (PostgreSQL + RLS + Auth + Storage) | RLSで permissive/restrictive 結合 |
| 認証 | couple=マジックリンク＋6桁ワンタイムコード / staff=メール＋パスワード | LINE内ブラウザのブラウザ跨ぎ対応 |
| 定期処理 | pg_cron | 表記散在の解消は要対応(rank 16) |
| AI補助 | ローカルLLM (Ollama) をプル型ジョブで内製、RAG は pgvector | 生成エンジンは校内サーバー非公開 |
| 通知 | LINE Messaging API / メール(Resend想定) | 送信設計は要詰め(rank 17) |
