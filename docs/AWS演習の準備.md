## 演習案

学校の指定がない場合、非公開S3バケットの構成を題材にします。保存するのは模擬のテキスト1件で、アプリのDBや個人情報を移しません。

1. 現行構成のStorageと比較し、バケット・アクセス制御・暗号化・削除の責任範囲を説明する。
2. `aws/school-storage-template.json`を読んで、公開防止、暗号化、所有権設定、終了時のリソース削除を確認する。
3. 学校の接続先が確定したら、担当者が以下の構文検証を行い、結果と実行版を保存する。

   ```sh
   aws cloudformation validate-template --template-body file://aws/school-storage-template.json
   ```

4. 実リソースの作成が課題要件の場合は、学校の利用条件に沿って担当者が別途実行する。作成したリージョン・スタック名・リソース名・開始日時を記録する。
5. 公開不可、許可されたロールの保存/読取、許可のない主体の拒否を模擬ファイルで確認する。
6. 終了時に模擬オブジェクトを空にし、作成したスタックだけを削除する。終了日時・リソース残存・費用確認を記録する。既存バケットを対象にしない。

このリポジトリのテンプレートはローカルでJSONとして検査済みの演習素材です。AWS上の構文検証・リソース作成・権限試験は未実施です。
