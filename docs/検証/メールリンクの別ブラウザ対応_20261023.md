# #105 メールリンクの別ブラウザ対応：統合・検証

基点は#104・#123統合済みの `9cceeec`、作業ブランチは `codex/resume-login-link`。GitHubのmainは `b426e99` と照合した。既存実装 `3690050` と元チェックアウトの未コミット試験を取り込んだ。元の作業場所は変更していない。

## 統合内容

- メールテンプレートとOTP要求の戻り先を `/login/link` に統一した。メールアドレスと6桁コードはフラグメントで渡し、着地後にURLから除去する。ボタン押下時だけ既存のOTP検証APIを呼ぶ。
- ログイン済みの別アカウントから開く場合は切替の案内を表示する。期限切れ・通信失敗・不正リンクはメールを保持した編集可能な再送フォームへ戻す。旧形式リンクの失敗時もメールとコードを入力できる。
- #104の安全な戻り先と#123の案内を保持した。#104の実メール試験は新しいフラグメント形式と確認ボタンに追従した。新規画面を性能ログの許可ルートに追加した。
- 基本設計6-3-1・P01・9章の改訂差分は [APIと更新境界](../詳細設計/APIと更新境界.md) に記載した。基本設計DOCX原本への反映は残る。

## 検証

型検査・lint・整形検査・進捗整合性検査・本番ビルドはすべて成功した。

| 対象                         | 結果                                                           |
| ---------------------------- | -------------------------------------------------------------- |
| 単体・PGlite                 | 990件成功、実PostgreSQL用15件skip                              |
| PC Chromium                  | 模擬認証の10件成功（#105の6件、#104の3件、既存OTP通信障害1件） |
| スマートフォン寸法のChromium | 同じ10件成功。実機・Safariの試験とは別                         |
| 実認証・Mailpit              | #104の2件・#105の2件が環境なしでskip                           |

模擬認証の6件は、独立したブラウザーコンテキストでの押下後の復帰、押下前の未検証とURLからのフラグメント除去、不正コード、期限切れ後のメールと戻り先の保持、検証中のボタン無効化、旧リンク失敗後の再入力を扱う。認証APIと復帰先HTMLを差し替えているため、実OTPの消費・再利用拒否や実アカウント切替の成功を証明するものではない。
