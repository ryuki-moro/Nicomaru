# AIデモの待ち時間の計測（#240）

台本の4つのAI操作で、ボタンを押してから結果（「採用する」ボタンなど）が出るまでの時間。各5回の中央値。

## 条件

- 計測日：2026-11-12
- PC：デモ画面・AIワーカー・Ollama をすべて同じPC（GPU: AMD Radeon RX 9070 XT、メモリ 64GB）
- モデル：`gemma3:12b`（Ollama、`OLLAMA_KEEP_ALIVE=60m` で読み込み済み）
- 起動：`npm run demo:all -- --connect local`（データは初期状態）
- 計測：`node scripts/demo-ai-latency.mjs 5`（Playwright でボタンを押し、結果が出るまでを測る）
- 自宅PCの ai-agent-lab を Tailscale 経由で呼ぶ構成は未計測（通信の分だけ延びる見込み）

## 結果

| 操作                                 | 変更前（秒） | 変更後（秒） | LLMの処理（変更後、秒） |
| ------------------------------------ | ------------ | ------------ | ----------------------- |
| 第1幕 宿題の起票（記録して案を作る） | 11.1         | 5.0          | 約3.8                   |
| 第2幕 不備チェック（表記ゆれ・敬称） | 6.0          | 4.5          | 約3.4                   |
| 第2幕 差し戻し文（文面の下書き）     | 6.0          | 4.4          | 約3.3                   |
| 第3幕 翻訳（英→日）                  | 5.5          | 4.4          | 約3.2                   |

各回の値（秒）：

- 変更前：起票 11.1 / 6.0 / 6.0 / 11.1 / 11.1、不備 6.0 / 6.0 / 6.0 / 6.0 / 5.9、差し戻し 5.5 / 11.1 / 6.0 / 11.2 / 6.0、翻訳 5.5 / 5.5 / 5.5 / 5.4 / 5.5
- 変更後：起票 5.0 / 5.0 / 4.5 / 4.5 / 5.0、不備 4.5 / 4.5 / 5.0 / 4.4 / 5.0、差し戻し 4.4 / 3.9 / 6.9 / 3.9 / 7.5、翻訳 4.4 / 4.4 / 3.9 / 4.5 / 5.0

LLMの処理時間はワーカーのログ（`完了 … ms`）から取った。台本.md にあった以前の実測（約6〜12秒）とは、LLMを動かすPCなどの条件が違う可能性がある（以前の条件は記録が無く未確認）。

## 何が待ち時間だったか・何を変えたか

| 内訳                             | 変更前                 | 変更後                                     | 範囲                      |
| -------------------------------- | ---------------------- | ------------------------------------------ | ------------------------- |
| 画面が結果を見に行く間隔         | 5秒（最大5秒待つ）     | 0.5秒                                      | `npm run demo` のときだけ |
| ワーカーがジョブを取りに行く間隔 | 2秒                    | 0.3秒                                      | `npm run demo:ai` だけ    |
| 宿題の起票のLLM出力              | 約240トークン・約4.4秒 | 約185トークン・約3.4秒（説明を40字以内に） | プロンプト v2（本番も）   |
| 画面の初回コンパイル             | 最初の1回だけ数秒      | 起動時に先に開いておく                     | `npm run demo:all` だけ   |

- 本物のLLMの出力をその場で使っている（先に答えを作って再生してはいない）。AIが使えないときの手入力・辞書翻訳は変えていない。
- 本番の画面が結果を見に行く間隔（5秒）とワーカーの既定（30秒）は変えていない。起票プロンプトの短縮は出力が減るので、本番の負荷は増えない。
- 差し戻し文はときどき 6〜7秒になる（LLMの処理が約6秒になる回がある）。出力の長さが回によって違うため。縮めるなら、次は差し戻し文のプロンプトで文面の長さに上限を付ける。
