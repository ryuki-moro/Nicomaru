# AIデモ 発表台本（3分）

プロジェクターは「拡張」にして、ノートPCに発表者の画面（デモ＋この台本＋タイマー）、プロジェクターに投影用の画面（デモの部分だけ）を出す。台本と操作ボタンは映らない。上の「◀ ▶」（または ← →）で導入 → 第1幕 → 第2幕と進めると、右の台本欄もその場面の節に切り替わる。左はダッシュボードから始まり、各幕の画面までその場でたどって見せる。新郎新婦に届いた様子は右のスマホで見せる。AIが遅いときの予備の画像も同じ画面に出せる。準備と困ったときの詳細は `台本.md`、質疑は `想定質問.md`。

この台本は発表者の画面の右に表示される（`### ` の見出しごとに、操作・（きっかけ）・> セリフ を読む）。見出しの書き方を変えないこと。

**伝えたいこと**：プランナーの「読む・書く」をAIが下ごしらえし、決めるのは人。AIは自宅PCで動くので、ゲストの個人情報を外部のAIサービスへ出さない。

## 想定される質問

質疑の答えは `想定質問.md`（約90問）。よく聞かれそうなものだけ：

- **AIが間違えたら？** 結果はすべて「要確認」で、自動では登録も送信もしません。確実なものはルール、気づきはAI、と役割を分けています。
- **個人情報は大丈夫？** AIは自分たちのPCで動き、外部のAIサービスには送りません。AIに渡すのは確認に要る列だけで、ゲストリストなら氏名や住所のような自由に書く列です（電話番号・郵便番号は渡しません）。
- **どのくらい速い？** 発表用のPCで、1回あたり約4.5〜5秒です（中央値。`gemma3:12b`）。改善前は5.5〜11秒でした。
- **AIが止まったら？** ルールのチェック、辞書での翻訳、手入力で、業務はそのまま続けられます。
- **ほかにどんなAI機能がある？** 英語などで届いた要望の翻訳（画像 07b）、担当交代のときの引き継ぎサマリー（画像 09）、届いた文章の自動仕分け（画像 07a）などがあります。
