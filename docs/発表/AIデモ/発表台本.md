# AIデモ 発表台本（3分）

画面の操作は実機（デモ画面）で行い、各場面の画像（`画面/`）はスライドに貼って予備にする。AIの結果が20秒を超えたら、その場面の画像に切り替えて話を続ける。操作の細かい手順は `台本.md` を参照。

## 伝えたいこと（1行）

> プランナーの「読む・書く・訳す」をAIが下ごしらえし、決めるのは人。AIは自宅PCで動くので、ゲストの個人情報を外部のAIサービスへ出さない。

## 事前準備（発表の直前）

新郎新婦の提出（不備入りのゲストリスト、英語のBGM希望）は、デモのデータに最初から入っている。手順の詳細は `台本.md` の「準備」。

1. デモを初期状態にし、ワーカーを起動する（`台本.md` の準備 3〜4）。
2. 左（プランナー）にタブを3つ用意する：石井様の「打ち合わせ記録」（`打ち合わせメモ.txt` を貼っておき、保存はまだ押さない）、「提出物確認」の石井様のゲストリスト、同じくBGMリクエスト。
3. スライドに画像 01〜08 を貼っておく。

## 締め（2:40〜3:00）

> ここまでのAIは、すべて自宅のPCで動いています。外部のAIサービスを使わないので、ゲストの名前や住所は外に出ません。AIの結果はどれも「要確認」で、決めるのは人です。AIが下ごしらえして、人が決める。これが、にこまるのAIです。

## うまくいかないとき

| 症状                             | その場の対応                                                           |
| -------------------------------- | ---------------------------------------------------------------------- |
| AIの結果が出ない（20秒以上）     | 「自宅PCで考えています」とつなぎ、画像に切り替えて話を続ける           |
| 「AI補助を利用できません」と出る | すべて画像で進める。裏でワーカーを起動し直す（`台本.md` の困ったとき） |
| 結果の中身が画像と少し違う       | AIの答えは毎回少し変わる。数が多少違っても、そのまま説明してよい       |
| 時間が押している                 | 第3幕を画像 07b・08 だけにして一言で済ませる                           |

## 想定される質問

- **Q. AIが間違えたら？** A. 結果はすべて「要確認」で、自動では登録も送信もしません。確実なものはルール、気づきはAI、と役割を分けています。
- **Q. 個人情報は大丈夫？** A. AIは自宅のPCで動き、外部のAIサービスには送りません。AIに渡すのは、処理に必要な項目だけです。
- **Q. どのくらい速い？** A. 1回あたり5〜10秒ほどです（`gemma3:12b`、GPU 1枚）。
- **Q. AIが止まったら？** A. ルールのチェック、辞書翻訳、手入力で、業務はそのまま続けられます。
- **Q. ほかにどんなAI機能がある？** A. 担当交代のときの引き継ぎサマリー（画像 09）、届いた文章の自動仕分け（画像 07a）などがあります。
