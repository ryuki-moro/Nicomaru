# AIデモ 発表台本（3分）

左にアプリの画面（プランナー）、スライドに画像 01〜08。操作するのはプランナー側のAIボタン4回だけで、新郎新婦に届く様子は画像で見せる。押す場所の画像付きの説明は `操作ガイド/操作ガイド.html`、準備と困ったときの詳細は `台本.md`。

**伝えたいこと**：プランナーの「読む・書く・訳す」をAIが下ごしらえし、決めるのは人。AIは自宅PCで動くので、ゲストの個人情報を外部のAIサービスへ出さない。

- [ ] スライドに画像 01〜08 を貼ってある

## 困ったとき

| 症状                                     | その場の対応                                                                            |
| ---------------------------------------- | --------------------------------------------------------------------------------------- |
| AIの結果が20秒たっても出ない             | 「自宅のPCで考えています」とつなぎ、その場面の画像（02・04・05・07b）に切り替えて続ける |
| 「ただいまAI補助を利用できません」と出る | すべて画像で進める。終わったら `台本.md` の「困ったとき」でワーカーを起動し直す         |
| AIの答えが画像と少し違う                 | AIの答えは毎回少し変わる。数が多少違っても、そのまま説明してよい                        |
| 時間が押している                         | 第3幕は画像 07b・08 だけにして一言で済ませる                                            |

## 想定される質問

- **AIが間違えたら？** 結果はすべて「要確認」で、自動では登録も送信もしません。確実なものはルール、気づきはAI、と役割を分けています。
- **個人情報は大丈夫？** AIは自宅のPCで動き、外部のAIサービスには送りません。AIに渡すのは、処理に必要な項目だけです。
- **どのくらい速い？** 1回あたり5〜12秒ほどです（`gemma3:12b`、GPU 1枚）。
- **AIが止まったら？** ルールのチェック、辞書での翻訳、手入力で、業務はそのまま続けられます。
- **ほかにどんなAI機能がある？** 担当交代のときの引き継ぎサマリー（画像 09）、届いた文章の自動仕分け（画像 07a）などがあります。
