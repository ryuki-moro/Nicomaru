# AIデモ 操作手順（3分版）

話す内容と時間配分は `発表台本.md`。ここは、準備と操作の手順、困ったときの対処をまとめる。

**伝えること**：プランナーの「読む・書く・訳す」をAIが下ごしらえし、決めるのは人。AIは自宅PCのローカルLLMで動くので、ゲストの個人情報は外部のAIサービスへ出ない。

## デモのデータ（`npm run demo -- --reset` で毎回この状態から始まる）

主役は石井 健太様・結衣様（案件 BRIDAL01-2027-0001、挙式は約70日後）。新郎新婦の提出は済んだ状態で入っている。

| 宿題             | 状態                                             | デモでの使い道                                                |
| ---------------- | ------------------------------------------------ | ------------------------------------------------------------- |
| ゲストリスト提出 | 確認待ち（`ゲストリスト_石井家.csv` を添付済み） | 第2幕：ルール3件＋AI3件の指摘 → 差し戻し文                    |
| BGMリクエスト    | 確認待ち（英語で提出済み）                       | 第3幕：英→日の翻訳（届いた時点でAIの分類も付く）              |
| 料理コースの選択 | 確認待ち                                         | 使わない                                                      |
| 引き出物の選択   | 確認済み                                         | 第1幕：メモの「引き出物は確定」をAIが宿題にしないことの裏付け |

ゲストリストにわざと入れてある不備（行番号はヘッダーの次を1行目とする）：

| 行           | 不備                                 | 見つけるもの |
| ------------ | ------------------------------------ | ------------ |
| 5行目        | ふりがなが空                         | ルール       |
| 8行目        | 3行目と同じ人（重複）                | ルール       |
| 9行目        | 郵便番号が6桁                        | ルール       |
| 4行目        | 氏名に「様」                         | AI           |
| 5行目・6行目 | 「株式会社ABC商事」と「(株)ABC商事」 | AI           |
| 9行目        | 住所の数字が全角（「２丁目１−１」）  | AI           |

素材（このフォルダ）：

- `打ち合わせメモ.txt`：第1幕でプランナーがメモ欄に貼る
- `ゲストリスト_石井家.csv`：デモのデータに添付済み（その場で提出し直すときに使う）
- `画面/`：各場面のスクリーンショット（AIが遅い・止まったときの予備）

## 準備（本番の30分前まで）

構成：デモ画面とAIワーカーはこのPC、LLMは自宅PC。ワーカーは Tailscale 経由で、自宅PCの ai-agent-lab の LLM生成窓口（`llm_gateway.py`、8766番）を呼ぶ。窓口が models.yaml の最適化を当てて Ollama を呼ぶ。

1. 自宅PCで Ollama と LLM生成窓口を起動する（`自宅PC_LLM窓口プロンプト.md` を自宅PCのAIアシスタントに渡すと用意できる）。デモ中は、自宅PCの ai-agent-lab で大きいモデルを使う作業をしない（GPUを取り合って遅くなる）。
2. このPCでブランチを取得して依存を入れる：`git fetch && git switch demo/ai-showcase && npm ci`
3. ターミナル1：`npm run demo -- --reset`（データを初期状態に戻して 3105 番で起動）
4. ターミナル2：AIワーカーを自宅PCにつなぐ
   - 初回：自宅PCの ai-agent-lab のダッシュボード「外部連携」で連携を追加し、「接続コードをコピー」したコードを渡す。
     ```powershell
     npm run demo:ai -- --connect "<接続コード>"
     ```
   - 2回目から：コードは `.ai-lab-connection`（git管理外）に覚えてあるので、`npm run demo:ai` だけでつながる。
   - 「起動しました」と出ればつながっている。モデルの読み込みと、60分の保持もここで行う。
   - 接続コードを使わず、`OLLAMA_ENDPOINT`・`OLLAMA_API_KEY`・`OLLAMA_MODEL` を直接指定してもよい（指定があればそちらを優先）。
   - `--reset` でデモをやり直したときは、ターミナル2も起動し直す（合言葉が作り直されるため）。
5. 画面を2つ並べる
   - 左（プランナー）：通常のウィンドウで http://127.0.0.1:3105/login →「パスワードでログイン（プランナー・管理者）」→「パスワードでログイン」（入力は空欄のまま）
   - 右（新郎新婦）：シークレットウィンドウ（ログインが混ざらないように）で同じURL →「確認コードを送信」。開発者ツールでスマホ幅（390px）にする。
6. 左のタブを3つ用意する（タブを切り替えるだけで次の場面に進める）
   - タブ1：案件一覧 →「石井 結衣 / 石井 健太」→「打ち合わせ記録」。`打ち合わせメモ.txt` の中身をメモ欄に貼っておく（保存はまだ押さない）
   - タブ2：「提出物確認」→ 石井様の「ゲストリスト提出」
   - タブ3：「提出物確認」→ 石井様の「BGMリクエスト」
7. スライドに `画面/` の 01〜08 を貼っておく

## 操作（3分）

| 場面  | 操作                                            | AIの待ち時間（実測） |
| ----- | ----------------------------------------------- | -------------------- |
| 第1幕 | タブ1で「記録して案を作る」                     | 約7秒                |
| 第2幕 | タブ2で「AIに表記ゆれ・敬称を見てもらう」       | 約7秒                |
| 第2幕 | 確認結果「不備あり」→「AIに文面の下書きを頼む」 | 約12秒               |
| 第3幕 | タブ3で翻訳先「日本語」→「AIに翻訳を頼む」      | 約6秒                |

結果を新郎新婦のスマホに届ける操作（宿題の登録、「確定する」）は、3分版では行わず画像 03・06・08 で見せる。時間に余裕があれば実機で行ってよい：

- 第1幕：案に期限を入れて「この案を宿題として登録する」→「起票案を採用する」→ 右の「宿題・提出物」に届く
- 第2幕：「下書きを採用する」→「確定する」→ 右のゲストリストに「プランナーからのご連絡」が届く
- 第3幕：翻訳する文面を返事に書き換え、翻訳先「英語」→「AIに翻訳を頼む」→「コメント欄に入れる」→「確認済」→「確定する」

## 困ったとき

| 症状                                     | 対処                                                                                                               |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 「ただいまAI補助を利用できません」と出る | ターミナル2が動いているか確認。止まっていれば準備4を再実行                                                         |
| ターミナル2に「つながりません」と出る    | 自宅PCの Ollama と窓口（llm_gateway.py）が起動しているか、Tailscale がつながっているか、合言葉が合っているかを確認 |
| ターミナル2に `401` が並ぶ               | デモを `--reset` で作り直した後。ターミナル2を起動し直す                                                           |
| 「AIが処理中」から進まない               | 画面を再読み込みし、もう一度依頼する（メモは再保存、チェックは同じボタン）                                         |
| 翻訳が遅い・失敗する                     | 「辞書で翻訳する（AI不要）」で定型文だけその場で訳せる                                                             |
| 最初からやり直したい                     | ターミナル1を止めて `npm run demo -- --reset`、続けてターミナル2を起動し直す                                       |
