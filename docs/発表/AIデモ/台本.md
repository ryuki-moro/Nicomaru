# AIデモ台本（約7分）

**伝えること**：プランナーの「読む・書く・まとめる」をAIが下ごしらえし、決めるのは人。AIは自宅PCのローカルLLMで動くので、ゲストの個人情報は外部のAIサービスへ出ない。

素材（このフォルダ）：`打ち合わせメモ.txt`（第1幕で貼る）、`ゲストリスト_石井家.csv`（第2幕で提出。わざと不備を入れてある）

## 準備（自宅PC・本番の30分前まで）

1. Ollama を起動し、使うモデルが入っていることを確認する（`ollama list`）。VRAM 12GB以上なら `gemma3:12b`、8GB なら `qwen2.5:7b` が目安。
2. このブランチを取得して依存を入れる：`git fetch && git switch demo/ai-showcase && npm ci`
3. ターミナル1：`npm run demo -- --reset`（データを初期状態に戻して 3105 番で起動）
4. ターミナル2：`$env:OLLAMA_MODEL='gemma3:12b'; npm run demo:ai`（PowerShell。モデル名は `ollama list` の表示どおり）
   - 「起動しました」と出ればつながっている。モデルの読み込みと、60分の保持もここで行う。
   - `--reset` でデモをやり直したときは、ターミナル2も起動し直す（合言葉が作り直されるため）。
5. 予行（モデルを温める）：プランナーで石井様以外の案件（例：青木様）を開き、「AIにサマリーを作り直してもらう」を1回押して、AIの要約に変わることを確かめる。
6. 画面を2つ並べる
   - 左（プランナー）：通常のウィンドウで http://127.0.0.1:3105/login →「パスワードでログイン（プランナー・管理者）」→「パスワードでログイン」（入力は空欄のまま）
   - 右（新郎新婦）：シークレットウィンドウ（ログインが混ざらないように）で同じURL →「確認コードを送信」。開発者ツールでスマホ幅（390px）にすると「スマホで見ている」感じが出る。

## 第1幕　打ち合わせメモ → AIが宿題を起票（2分）

1. 左：案件一覧 →「石井 健太・石井 結衣」→「打ち合わせ記録」
2. `打ち合わせメモ.txt` の中身を「メモ」に貼り、「記録して案を作る」
   > 「打ち合わせのメモを保存するだけで、AIが新郎新婦への宿題を拾い出します」
3. 「AIによる起票案（要確認）」に宿題案が並ぶ（AIの目安つき）。1〜2件に期限を入れて「この案を宿題として登録する」→「起票案を採用する」
   > 「期限はAIに決めさせず、目安を見てプランナーが決めます。AIは下ごしらえ役です」
4. 右：「宿題・提出物」を開くと、いま登録した宿題が届いている

## 第2幕　ゲストリストの不備をAIが指摘 → 差し戻し文もAIが下書き（3分）

1. 右：「ゲストリスト提出」→ `ゲストリスト_石井家.csv` を選んで「提出する」
2. 左：「提出物確認」→「ゲストリスト提出」の行を開く
3. 「AIによる一次チェック」：ルールが 未入力・形式・重複 の3件を即座に指摘
   > 「機械的に分かるものはルールで、AIが止まっていても必ず出ます」
4. 「AIに表記ゆれ・敬称を見てもらう」→ 氏名に付いた「様」、「株式会社／(株)」、「一丁目／1-」などをAIが行番号つきで指摘
   > 「人が見落としやすい“表記ゆれ”や“敬称”は、AIが疑いとして挙げます」
5. 確認結果で「不備あり」を選ぶ →「一次チェックの指摘○件を材料に下書きします」と出る →「AIに文面の下書きを頼む」
6. 行番号つきの丁寧な差し戻し文ができる →「下書きを採用する」→（必要なら一言直して）「確定する」
   > 「指摘を拾って、角の立たない文面まで。プランナーは確認して送るだけです」
7. 右：宿題を開き直すと「不備あり」と「プランナーからのご連絡」が届いている

## 第3幕　担当交代の引き継ぎサマリー（1分）

1. 左：「石井」の案件詳細 →「AIによる引継ぎサマリー」→「AIにサマリーを作り直してもらう」
   > 「急な担当交代でも、ボタン1つで状況・決定事項・注意点がまとまります」

## 締め（1分）

- AIは自宅PCのローカルLLM（Ollama）。アプリはジョブを置くだけで、AI側が取りに来る形なので、LLMを外部に公開せず、個人情報も外部のAIサービスへ出ない。
- AIの出力はすべて「要確認」。採用・登録・送信は人が決める。
- AIが止まっても、ルールによるチェックと手入力で業務は止まらない。

## 困ったとき

| 症状                                     | 対処                                                                                                                     |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 「ただいまAI補助を利用できません」と出る | ターミナル2が動いているか確認。止まっていれば `npm run demo:ai` を再実行                                                 |
| ターミナル2に `401` が並ぶ               | デモを `--reset` で作り直した後。ターミナル2を起動し直す                                                                 |
| 「AIが処理中」から進まない               | AIの出力が形式に合わず再試行待ちのことがある。画面を再読み込みし、もう一度依頼する（メモは再保存、チェックは同じボタン） |
| 遅い（1回30秒以上）                      | 小さいモデルに替える：`$env:OLLAMA_MODEL='qwen2.5:7b'; npm run demo:ai`                                                  |
| 最初からやり直したい                     | ターミナル1を止めて `npm run demo -- --reset`、続けてターミナル2を起動し直す                                             |
