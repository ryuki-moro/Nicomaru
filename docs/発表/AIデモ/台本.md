# AIデモ 操作手順（3分版）

話す内容と時間配分は `発表台本.md`。ここは、準備と操作の手順、困ったときの対処をまとめる。

**伝えること**：プランナーの「読む・書く・訳す」をAIが下ごしらえし、決めるのは人。AIは自宅PCのローカルLLMで動くので、ゲストの個人情報は外部のAIサービスへ出ない。

## デモのデータ（`npm run demo -- --reset` で毎回この状態から始まる）

主役は石井 健太様・結衣様（案件 BRIDAL01-2027-0001、挙式は約70日後）。新郎新婦の提出は済んだ状態で入っている。

| 宿題             | 状態                                             | デモでの使い道                                                |
| ---------------- | ------------------------------------------------ | ------------------------------------------------------------- |
| ゲストリスト提出 | 確認待ち（`ゲストリスト_石井家.csv` を添付済み） | 第2幕：ルール3件＋AI3件の指摘 → 差し戻し文                    |
| BGMリクエスト    | 確認待ち（英語で提出済み）                       | 第3幕：英→日の翻訳（届いた時点でAIの分類も付く）              |
| 料理コースの選択 | 確認待ち                                         | 使わない                                                      |
| 引き出物の選択   | 確認済み                                         | 第1幕：メモの「引き出物は確定」をAIが宿題にしないことの裏付け |

ゲストリストにわざと入れてある不備（行番号はヘッダーの次を1行目とする）：

| 行           | 不備                                 | 見つけるもの |
| ------------ | ------------------------------------ | ------------ |
| 5行目        | ふりがなが空                         | ルール       |
| 8行目        | 3行目と同じ人（重複）                | ルール       |
| 9行目        | 郵便番号が6桁                        | ルール       |
| 4行目        | 氏名に「様」                         | AI           |
| 5行目・6行目 | 「株式会社ABC商事」と「(株)ABC商事」 | AI           |
| 9行目        | 住所の数字が全角（「２丁目１−１」）  | AI           |

素材（このフォルダ）：

- `打ち合わせメモ.txt`：第1幕でプランナーがメモ欄に貼る
- `ゲストリスト_石井家.csv`：デモのデータに添付済み（その場で提出し直すときに使う）
- `画面/`：各場面のスクリーンショット（AIが遅い・止まったときの予備）

## 準備（本番の30分前まで）

構成：デモ画面とAIワーカーはこのPC。LLMは自宅PC（Tailscale 経由で ai-agent-lab の LLM生成窓口 `llm_gateway.py` を呼ぶ）か、このPCの Ollama。

1. 自宅PCを使うときは、自宅PCで Ollama と ai-agent-lab の `llm_gateway.py`（`feat/llm-gateway` ブランチ。待受先と合言葉は `GATEWAY_HOST`・`GATEWAY_PORT`・`GATEWAY_TOKEN`）を起動しておく。デモ中は、自宅PCで大きいモデルを使う作業をしない（GPUを取り合って遅くなる）。このPCの Ollama だけで行うときは不要。
2. プロジェクターをつなぎ、Windows の表示を「拡張」にする（Win + P →「拡張」）。
3. リポジトリの `AIデモを始める.bat` をダブルクリックする。約30秒で、ノートPCに発表者の画面（Edge）が開く。
   - 初回だけ、接続コードを聞かれる。自宅PCの ai-agent-lab のダッシュボード「外部連携」で「接続コードをコピー」して貼り付ける。このPCの Ollama なら `local`（`local?model=qwen2.5:7b` のようにモデルも指定できる）。コードは `.ai-lab-connection`（git管理外）に覚える。
   - 中では `npm run demo:all` が動いている（データの初期化・アプリ・AIワーカー・モデルの読み込み）。そのウィンドウはタスクバーに最小化してある。
4. 発表者の画面で「投影を開始」→ 出てきた確認で「許可」（このタブを共有）。開いた投影用のウィンドウをプロジェクター側へドラッグし、ダブルクリックで全画面にする。

発表者の画面：

- 左にプランナー、右にスマホ幅の新郎新婦。どちらもログイン済みで、打ち合わせメモも入力済み（保存はまだ）。
- 右端に台本（`発表台本.md` のその場面の節）、上にタイマー（最初に ▶ を押すと数え始め、3分を超えると赤くなる）。
- 投影用の画面には、デモの部分（左右の画面と説明用の画像）だけが映る。台本・上のボタン・タイマーは映らない。マウスの動きは映る。
- 右の新郎新婦の画面は、左を操作したあとマウスを右に動かすと自動で開き直す。すぐ見せたいときは「右を更新」。
- 最初からやり直すときは「やり直す」。データだけ初期状態に戻り、AIワーカーは動いたまま（約30秒）。
- 終わったら `AIデモを終わる.bat` をダブルクリックする（アプリとAIワーカーをまとめて止める）。
- 投影せずに練習するときは、発表者の画面だけで通せる。ブラウザは Chrome か Edge（投影の切り取りは、この2つでしか動かない）。
- これまでどおり `npm run demo` と `npm run demo:ai` を別々に起動してもよい。その場合、左右並べや投影は使えない。

## 操作（3分）

| 場面  | 操作                                            | AIの待ち時間（実測・中央値） |
| ----- | ----------------------------------------------- | ---------------------------- |
| 第1幕 | ①で「記録して案を作る」                         | 約5秒                        |
| 第2幕 | ②で「AIに表記ゆれ・敬称を見てもらう」           | 約4.5秒                      |
| 第2幕 | 確認結果「不備あり」→「AIに文面の下書きを頼む」 | 約4.5秒                      |
| 第3幕 | ③で翻訳先「日本語」→「AIに翻訳を頼む」          | 約4.5秒                      |

待ち時間は `待ち時間の計測.md`（このPCの Ollama で測った値。自宅PCを経由すると通信の分だけ延びる）。

結果を新郎新婦のスマホに届ける操作（宿題の登録、「確定する」）は、3分版では行わず画像 03・06・08 で見せる。時間に余裕があれば実機で行ってよい：

- 第1幕：案に期限を入れて「この案を宿題として登録する」→「起票案を採用する」→ 右の「宿題・提出物」に届く（マウスを右へ動かすと表示される）
- 第2幕：「下書きを採用する」→「確定する」→ 右のゲストリストに「プランナーからのご連絡」が届く
- 第3幕：翻訳する文面を返事に書き換え、翻訳先「英語」→「AIに翻訳を頼む」→「コメント欄に入れる」→「確認済」→「確定する」

## 困ったとき

| 症状                                              | 対処                                                                                                                                        |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 「ただいまAI補助を利用できません」と出る          | タスクバーの「にこまる AIデモ」のウィンドウに `[AI]` のエラーが出ていないか確認。止まっていれば `AIデモを終わる.bat` → `AIデモを始める.bat` |
| `[AI]` に「届きません」「合言葉が違います」と出る | 自宅PCの Ollama と窓口（llm_gateway.py）が起動しているか、Tailscale がつながっているか、合言葉が合っているかを確認                          |
| 接続コードを貼り間違えた                          | `.ai-lab-connection` を消して `AIデモを始める.bat` をやり直す（もう一度聞かれる）                                                           |
| 投影用の画面が真っ黒・止まっている                | 発表者の画面を最小化していないか確認（隠れると映像が止まる）。直らなければ「投影を開始」を押し直す                                          |
| 「前のAIデモが動いています」と出る                | `AIデモを終わる.bat` を実行してから、もう一度始める                                                                                         |
| 「AIが処理中」から進まない                        | 発表者の画面を再読み込み（F5）し、もう一度依頼する（メモは再保存、チェックは同じボタン）                                                    |
| 翻訳が遅い・失敗する                              | 「辞書で翻訳する（AI不要）」で定型文だけその場で訳せる                                                                                      |
| 最初からやり直したい                              | 発表者の画面の「やり直す」（AIワーカーは起動し直さなくてよい）                                                                              |
