# 案件番号の表示方針

Issue #219 の確認結果として、案件番号はスタッフ向け画面だけに表示する。

## 判断

- 案件番号とその採番は維持する。DB上の識別、監査、ログ、スタッフの案件照合には引き続き使う。
- プランナー・式場管理者などのスタッフ画面では、案件一覧や提出物確認、運用記録の照合に使うため表示を維持する。
- 新郎新婦のマイページでは表示しない。招待後は自分の案件に紐づく情報を画面で直接確認でき、番号を検索・伝達する操作がない。氏名や挙式日など、本人に意味のある情報を優先する。
- 新郎新婦から問い合わせ時に番号を聞かれる運用が確認された場合は、「お問い合わせ番号」として再掲するか、スタッフ側で検索できる導線を検討する。

## 根拠と限界

既存のUIレビュー `docs/ui-review/p2/review.md` では、案件番号は新郎新婦が使う場面がなく、挙式情報で業務用語として目立つと記録されている。またスタッフ側には、案件一覧、提出物確認、通知・運用記録の照合がある。直近の利用者からも画面上の案件番号の必要性に疑問が示された。

この決定は既存画面・レビュー記録・利用者の懸念からの判断であり、式場スタッフへの追加ヒアリングに基づく事実確認ではない。デモではスタッフ側表示を保ち、新郎新婦側だけ非表示にする。
