# 画面のスクリーンショット

にこまるの主要画面を撮って残したものです（Issue #28・#210）。発表資料・README・式場への説明に使います。
すべて模擬データ（架空の人名・`.test` ドメインのメールアドレス）で撮影しています。

## 撮り直し方

前提は `npm install` 済みであることだけです。Docker・Supabase・`.env.local` は要りません。

1つ目のターミナルで、デモを最初の状態から起動します（http://127.0.0.1:3105 で待ち受けます）。

```bash
npm run demo -- --reset
```

「デモの準備完了」と出たら、2つ目のターミナルで撮影します。

```bash
npm run screenshots
```

`npm run screenshots` は `scripts/screenshots.mts` を実行し、このフォルダの画像を同じファイル名で上書きします。

- ログインはデモのログイン画面と同じ操作です（入力は空欄のまま）。「確認コードを送信」で新郎新婦（demo-02 の石井さま）、「パスワードでログイン」でプランナーとして入ります。パスワードやコードはスクリプトに書いていません。
- 席次の画面に写すものが無いと空の案内だけになるため、配置パターンが1つも無ければ、スクリプトがプランナーの画面操作で1つ作って新郎新婦に送ります。デモのデータが変わるので、撮り直す前は毎回 `--reset` 付きでデモを起動し直してください。
- Playwright のブラウザ（`npx playwright install`）を入れていない場合は、手元の Chrome か Edge を指定して撮れます。

  ```bash
  PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH="C:/Program Files/Google/Chrome/Application/chrome.exe" npm run screenshots
  ```

- デモ以外のサーバーを撮るときは `SCREENSHOT_BASE_URL` に URL を入れます（ログイン画面にデモのログインがある環境に限ります）。

## 撮影の仕様

| 区分 | 画面サイズ | 撮り方 |
| --- | --- | --- |
| PC | 1440×900 | 画面全体（長いページは下までスクロールして全部）。新郎新婦の下部ナビは隠す |
| スマホ | 390px（iPhone 13） | 1画面ぶん。下部ナビは見えたまま |
| 部分 | 1440×900 | 案件詳細の中のセクションだけを切り出す（32） |

- Next.js の開発用バッジ（左下の N）は、どの画像にも写らないように隠しています。
- ログイン画面には、デモであることの案内（「デモ版です。入力は空欄のままで…」）が写ります。

## 注意

- AI 補助のパネルは、AI ワーカーが動いていないと「ただいまAI補助を利用できません」と表示されます。デモではそのときの画面を撮っています。
- 新しい画面を足すときは、既存の番号（01〜32）を変えず、33 以降に続けてください。
- プランナー側の「席次の確認」は、新郎新婦が席次を提出してから中身が出ます。デモの案件にはまだ出席のゲストがいないため提出できず、撮っていません（撮るときは 33 番にします）。
