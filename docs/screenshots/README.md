# 画面のスクリーンショット

にこまるの主要画面を撮って残したものです（Issue #28）。発表資料・README・式場への説明に使います。
すべて模擬データ（架空の人名・`.test` ドメインのメールアドレス）で撮影しています。

## 撮り直し方

前提: Docker Desktop が動いていて、`.env.local` が用意されていること。

```bash
npx supabase start
npm run demo:reset -- --login-links
npm run dev
```

別のターミナルで撮影します。

```bash
npm run screenshots
```

`npm run screenshots` は `scripts/screenshots.mts` を実行します。何度実行しても同じ画面を同じファイル名で撮り直せます。

- プランナーは `planner@nicomaru.test` でパスワードログインします。
- 新郎新婦は `demo-02-groom@demo.nicomaru.test` でログインします。メール欄にアドレスを入れ、Mailpit（http://127.0.0.1:54324）に届いた6桁のコードを入力します。

## 撮影の仕様

| 区分 | 画面サイズ | 撮り方 |
| --- | --- | --- |
| PC | 1440×900 | 画面全体（長いページは下までスクロールして全部）。新郎新婦の下部ナビは隠す |
| スマホ | 390px（iPhone 13） | 1画面ぶん。下部ナビは見えたまま |

- Next.js の開発用バッジ（左下の N）は、どの画像にも写らないように隠しています。
- アプリの URL は `.env.local` の `APP_BASE_URL` に合わせます（送信元の検証があるため、`127.0.0.1` と `localhost` を混ぜると 403 になります）。

## 注意

- AI 補助のパネルは、ローカル LLM が起動していないと「ただいまAI補助を利用できません」と表示されます。そのときの画面を撮っています。
- 新しい画面を足すときは、既存の番号（01〜30）を変えず、31 以降に続けてください。
