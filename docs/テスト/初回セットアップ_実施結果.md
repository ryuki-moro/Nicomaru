## つまずいた点と対処

1. **`git pull` がローカルの `package.json` の変更で止まった**
   以前の `npm install`／`npm audit fix` で `package.json` と `package-lock.json` が書き換わっていたと考えられる。`git stash` で変更をよけてから `git pull` し、`npm install` をやり直して解消した。
   → 手順書「困ったとき」に対処を追記した。`npm audit fix` を実行しないことも書いた。
2. **手順書で、起動のしかたが見つけにくかった**
   「準備（最初の1回だけ）」は `npm install` で終わっており、起動のしかたは文書の末尾（D1の節）にしか書かれていない。
   → 「準備の仕上げ」に `npm run demo` と開くURLを追記した。
3. **Node.js の準備が手順書に書かれていない**
   「道具を入れる」は GitHub Desktop／SourceTree だけで、Node.js の版の条件がない。
   → Node.js 22.13以上（または24以上）を入れることを追記した。
4. **Issue #142 本文の手順が古い**
   本文はSupabase時代の手順（Docker・ローカルSupabase・`npm run demo:seed`・`http://127.0.0.1:3000`）のまま。現行は README・手順書の `npm run demo`（3105番）で、Docker は不要。
