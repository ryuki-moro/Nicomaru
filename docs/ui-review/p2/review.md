# UIレビュー P2（feature/ui-p1-polish 時点）

- 実施日: 2026-10-22
- 対象: ブランチ `feature/ui-p1-polish`（`9ad35a7`）、`npm run demo:reset` の模擬データ
- 見た幅: PC 1440px／スマホ iPhone 13（390px）
- 入り方: プランナーはパスワード、新郎新婦は Mailpit の6桁コード（`scripts/screenshots.mts` と同じ経路）
- このフォルダの画像が根拠のスクショ。ファイル名の先頭は指摘番号（例 `h1-…` は高-1）

## やったこと

1. `scripts/screenshots.mts` と同じ撮影処理で全30画面を撮って確認した。`docs/screenshots/` を書き換えないよう、出力先だけを一時フォルダに変えて動かした
2. 一時フォルダの Playwright スクリプトで、プランナー側17画面・新郎新婦側10画面を PC とスマホで機械的に確認した（横はみ出し、名前のない操作要素、44px 未満のタップ領域、下部ナビとの重なり、`aria-current`）
3. 主な流れは最後まで操作した
   - プランナー: ダッシュボード → 案件一覧 → 案件詳細 → 提出物確認 → 確認結果「確認済」を登録
   - 新郎新婦: マイページ → 宿題 → テキスト提出・ファイル提出（CSV／PNG）
4. エラーと確認の表示を出して確かめた
   - ログイン: 空欄、形式違い、パスワード違い、送信回数の上限
   - 提出物確認: 未選択、不備ありでコメントが空
   - 宿題提出: 回答が空、ファイル未選択、形式違い
   - 「対応不要にする」の行内確認、存在しないURL、権限のない画面
5. 終わったあと `npm run demo:reset` で模擬データを戻した。リポジトリには、このフォルダ以外の変更はない

**範囲外・確認できなかったこと**
- 管理者（admin／system_admin）の模擬アカウントがないため、`/templates`・`/venues`・`/users`・`/plan-types` の中身は見ていない。プランナーで開いたときの動きだけ確認した（低-8）
- 差し戻しの確定と削除・アーカイブは実行していない。確認表示までにとどめた
- `docs/用語集.md` には開発用語（RLS・CI など）しか載っておらず、画面用語（宿題・提出物・差し戻し・不備あり・確認待ち）の定義がない。観点2の「用語集との照合」はできず、画面どうしの表記揺れだけを見た

### 高-1 「提出済」の色が画面ごとに違い、「確認済」と同じ緑にもなる

- **画面**: `/submissions`（PC・スマホ）、`/submissions/[id]`（PC・スマホ）、`/cases/[id]`、`/mypage/tasks`、`/mypage/tasks/[id]`
- **問題**: 同じ「提出済」が、2種類の色で出る。
  - 提出物確認の一覧と詳細の見出し横では**黄**（`ReviewStatusBadge`、`badge-warning`）
  - 提出物確認詳細の「宿題の状態」、案件詳細の宿題一覧、新郎新婦の宿題一覧では**緑**（`TaskStatusBadge`、`badge-success`）。この緑は「確認済」とまったく同じ色（`h1-pc-submission-review.png` では、同じ画面の上下で黄と緑になっている）
- **なぜ困るか**: 案件詳細の宿題一覧では「提出済（まだ確認していない）」と「確認済（確認が終わった）」が同じ緑で並ぶ。プランナーが色で流し見すると、確認待ちを済んだものと読み違え、確認漏れにつながる。新郎新婦も、提出しただけで「終わった（OK が出た）」と受け取りやすい。
- **改善案**: タスク状態の `submitted` を、確認待ちを表す `badge-warning`（または info 系）にそろえ、`confirmed` だけを緑にする。2つの対応表（`TASK_TONE` と `REVIEW_TONE`）で同じ状態名の色を一致させる。新郎新婦向けの表示名は、「確認待ち」のように相手の番だと分かる言葉も候補になる（中-6 と合わせて検討）。
- **該当**: `src/components/ui/StatusBadge.tsx:16`（`submitted: 'badge-success'`）と `:18`、`:28`
- **根拠**: `h1-pc-submissions-list.png`、`h1-pc-submission-review.png`、`h1-sp-couple-tasks.png`
