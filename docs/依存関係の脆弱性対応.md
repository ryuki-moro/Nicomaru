# 依存関係の脆弱性対応（Issue #47）

2026-10-06の `npm audit` で検出されたCritical 2件・High 9件・Moderate 3件を解消した。CIの監査閾値（High以上）と秘密情報検査は維持する。

- Vitestを4.1.11以上の4系へ更新し、脆弱なtinypoolと旧mockerを除去。DBテストの直列実行とテストごとの分離は維持する。
- Tailwindを4.3.3へ更新し、`@tailwindcss/postcss`で処理する。従来のテーマは `@config` で読み込み、バッジの共通宣言と強制色モード用のフォーカス指定を移行する。Autoprefixerは新しいプラグインに処理が含まれるため不要になる。
- source-map-jsとbrace-expansionを互換性のある修正版へロック更新する。
- 開発時のNode.jsは22.13以上の22系、または24以上を使う。CIはNode 22の最新パッチ版を使用する。

## Next.js lintプラグインの一時固定

10月6日時点ではNext.js本体と `eslint-config-next` を15.5.24に維持した（10月9日に15.5.27へ更新、後述）。15系と調査時点の最新版16.3.8の `@next/eslint-plugin-next` は、修正版のないbracesへfast-glob経由で依存していたため、プラグインだけ公式14.2.35を直接の開発依存として固定し、overrideする。その依存globは10.5.0へ更新する。直接依存を宣言することで、クリーンインストール後もFlatCompatがプロジェクト直下で解決できる。

14系にはESLint 9で削除されたルールAPIの呼び出しがあるため、[公式の互換ユーティリティ](https://eslint.org/blog/2024/05/eslint-compatibility-utilities/)で補う。ルールの無効化や監査の除外では対応しない。有効ルール99件が従来と一致することを確認し、Document内の重複Head・ページ内Google Fonts・画像代替テキスト・Service Role Keyの直接参照を負例で検証した。恒久テストは `tests/unit/eslint-config.test.ts` に置く。

上流プラグインが安全な依存へ移行したら、監査とこの負例テストを通してoverrideと互換層を外す。この固定はアプリのNext.js実行版を変更しない。

## 表示・検証

共通部品を実際の生成CSSで描画し、更新前後の360px最大幅・28px横余白・文字サイズ・色・角丸・バッジを比較した。Tailwind 4の `space-y-*` は兄弟の余白を末尾側へ付けるため、同じ部品に `mb-*` がある箇所では縦の間隔が数px変わる場合がある。印刷では `.no-print` を隠し、シート本体の見出しを表示する指定を維持する。

Tailwind 4の対応基準はSafari 16.4以上、Chrome 111以上、Firefox 128以上。既存E2EのデスクトップChromiumとスマートフォンWebKitを継続する。[公式移行ガイド](https://tailwindcss.com/docs/upgrade-guide)

ローカルでは依存監査0件、全体lint・型検査・単体/RLSテスト・本番ビルドを検証する。実PostgreSQLの並行性とSupabase上の画面操作はCIで確認する。

## 2026-10-09の追加対応

Next.jsを15.5.24から15.5.27へ、`eslint-config-next` も15.5.27へ同時に固定更新した。対象は公式アドバイザリ [GHSA-4jqv-mc3x-m676](https://github.com/vercel/next.js/security/advisories/GHSA-4jqv-mc3x-m676) と [GHSA-mcj8-r9mp-w47p](https://github.com/vercel/next.js/security/advisories/GHSA-mcj8-r9mp-w47p)。Next.js 15系のパッチ更新に限定している。

Next.jsのoptional dependencyであるsharpを0.35.4から0.35.5へlockfile更新し、`@img/sharp-libvips-*` パッケージも1.3.4へ更新した。対象はlibrsvg依存のHigh脆弱性 [GHSA-wq5f-xc86-pv6w](https://github.com/lovell/sharp/security/advisories/GHSA-wq5f-xc86-pv6w)。Next.jsが宣言する許容範囲内の更新で、sharpへのoverrideは追加していない。

更新後の `npm audit --json` はCritical・High・Moderate・Low・Infoすべて0件、合計0件。`tests/unit/eslint-config.test.ts` は5件成功し、有効ルール99件と負例の検出を確認した。既存の `@next/eslint-plugin-next@14.2.35`・`glob@10.5.0` の固定と `@eslint/compat` を維持し、CIの監査閾値と秘密情報検査は変更していない。
