# 簡易デモのデモ用AI

ログイン不要の簡易デモ（`npm run demo:static`）に入っているAI補助の範囲と限界。
実装は `demo/ai.mjs`、画面への組み込みは `demo/app.mjs`、採用結果の保存は `demo/model.mjs`。

## これは何か

本番のAI補助（基本設計 9-1〜9-5、本体は `src/lib/ai/` と `worker/ai-worker.ts`）を、
発表・説明の場でログイン不要デモでも触れるように、**実LLMを使わずルールと
テンプレートだけで再現したもの**。ブラウザの中で同期的に動き、外部送信は一切しない
（デモサーバーのCSPも `connect-src 'none'` のまま）。

画面には「デモ用AI：ブラウザ内でルール判定しています（実LLMではありません）」と表示する。
処理がその場で終わるため、本番のような「依頼中」「利用不可」の状態は作らない。

## 機能と置き場所（プランナー側のみ。新郎新婦側には出さない）

| 本番の機能           | デモでの再現                                                                                                                  | 画面                         |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| 9-1 自由記述の分類   | キーワード辞書のスコアリング。ラベルは本番 `schemas.ts` と同じ10種、確信度つき                                                | 案件詳細の提出済み宿題カード |
| 9-4 不備チェック     | 本番 `src/lib/ai/defectCheck.ts` のルールベース①（必須欠損・形式違反・重複・行数）を素のJSへ移植。提出がCSV形式のときだけ対象 | 同上                         |
| 9-3 文面下書き       | 目的別テンプレート（差し戻し／お礼など）へお名前・宿題名・期限を差し込み、`cautions`（確認点）も返す                          | 差し戻しモーダル内           |
| 9-2 準備シート下書き | 未提出・確認待ち・メモの分類をテンプレートで要約                                                                              | 準備シート冒頭のパネル       |
| 9-5 宿題起票案       | 打ち合わせメモを文分割し、「12月10日まで」「挙式2か月前」などの期限表現を `due_hint` として抽出                               | 同上                         |

## 原則

- AIの結果は「採用」操作で初めて本文（分類ラベル・準備シート・宿題一覧・差し戻し文面の入力欄）へ反映される。
- AIが自動送信・自動確定することはない。文面下書きは入力欄へ入るだけで、送信は人のボタン操作。
- 未採用の作業結果は保存しない（localStorage の state に乗るのは採用済みのものだけ）。

## 限界（実LLMとの違い）

- 分類は辞書にある言葉しか拾えない。言い換えや文脈の理解はできない。手がかりが無い文章は「その他」（確信度0.3）になる。
- 不備チェックは決定的に判定できるものだけ。本番の②（LLMによる表記ゆれ・敬称の疑い提示）は再現していない（辞書①のみ）。
- 起票案の題名は文の切り取り、日付の解決は「挙式Nか月前＝30日×N」の近似。内容の妥当性は人が確認する。
- 文面は固定テンプレートなので、案件ごとの事情は `cautions` を見て人が追記する前提。

## 検証

```bash
npm run test:demo   # tests/demo/ai.test.mjs（分類・下書き・不備チェック・起票案・採用保存）
```
